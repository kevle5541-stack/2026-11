# Re:Store

AI 기반 매장 자산 정리 서비스

## 프로젝트 소개
매장 사진을 업로드하면 AI가 판매 가능한 물품을
인식하고, 참고 시세와 적합한 판매 경로를 추천합니다.

## 해결하려는 문제
매장을 정리하는 소상공인은 물품 목록 작성,
중고 시세 조사, 판매 경로 탐색 등에
상당한 시간과 노력을 들여야 합니다.

## 핵심 기능
1. 매장 사진 여러 장 업로드
2. AI 물품 종류 및 수량 자동 추출
3. 물품 정보 수정 및 모델명 추가
4. 근거 있는 중고 참고 시세 제공
5. 판매 경로 추천 및 판매글 자동 생성

## 기술 스택
- Frontend: React + TypeScript
- Backend: Python + FastAPI
- AI: OpenAI API
- Database: Supabase (예정)

## 개발 상태
현재 MVP 개발 준비 단계입니다.

## 초기 MVP 지원 물품군 5종
1. 에스프레소 머신
2. 커피 그라인더
3. 업소용 제빙기
4. 쇼케이스 냉장고
5. 카페 가구 (테이블·의자)
